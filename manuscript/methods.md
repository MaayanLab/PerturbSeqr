# Web Server Application

The Perturb-Seqr search engine inherits its architecture from previous Ma'ayan Lab signature search engines as described in Rummagene21, RummaGEO17, and L2S222. In particular, Perturb-Seqr stores bit-vectors in random access memory (RAM) for extremely efficient processing of the Fisher's exact test via a standalone Rust API, empowering users to receive rapid results when searching the 434,314 gene sets. Perturb-Seqr also utilizes the paired gene set search to identify mimickers and reversers and consensus search as described in L2S222.

A mimicker is defined as the sum of the intersection between the user-submitted and database up-gene-sets and the intersection between the user-submitted and database down-gene sets, and a reverser is analogously defined across opposite directions 23. In paired gene set search, these overlaps fill the entries in the contingency table for computing the Fisher's exact test, and Benjamini-Hochberg24 adjusted p-values are computed within each library to correct for multiple hypotheses testing.

Since Perturb-Seqr often returns thousands of signature-level results, it can be difficult to interpret how a given perturbation will act across different cell contexts, timepoints, and concentrations. Consensus search addresses this by aggregating signatures sharing the same perturbation, grouped by PubChem Compound ID (CID) when available falling back to otherwise, and applying the Fisher's exact test to compare the counts of significant and insignificant signatures in the top-N results (default N = 10,000) as described in L2S222. Consensus mechanisms of action (MOAs) are computed similarly by grouping signatures by their annotated MOA25. Benjamini-Hochberg24 adjusted p-values are applied separately to the consensus perturbation and consensus MOA results.

The Perturb-Seqr web server application enhances the previous enrichment engine API, enabling users to select from 16 gene set libraries, thus allowing for more expansive yet tailored searches. Because these libraries originate from platforms with distinct gene coverage — for example, L1000 measures approximately 10,000 genes while RNA-seq-based datasets cover more than 20,000 — using a single global background for Fisher's exact test would violate the test's assumption that every gene in the background is a plausible member of any gene set. To address this, Perturb-Seqr computes Fisher's exact test for each gene set against a dataset-specific background defined as the union of all genes appearing in that gene set's library. This ensures that the contingency table for each gene set is internally consistent: the query genes, gene set genes, and background all reside in the same gene universe. As a result, p-values are a stable property of each gene set and are reproducible regardless of which libraries a user selects for display. Benjamini-Hochberg24 correction is applied independently within each library, consistent with the per-library Fisher's test: each gene set's adjusted p-value reflects correction over the number of gene sets in its own library, not the total across all libraries. This ensures that adjusted p-values, like raw p-values, are an intrinsic property of each gene set and its library, unaffected by the presence or selection of other libraries. Library selection then filters the displayed results without altering p-values. In practice, a search of paired 500 up- and down-regulated genes against all 434,314 gene sets completed in under one second. Programmatic access to all web server application features is made available by a GraphQL API at https://perturbseqr.k8s.dev.maayanlab.cloud/graphiql.
